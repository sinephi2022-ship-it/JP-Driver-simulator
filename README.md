# 路上教習シミュレーター

面向驾校学员的日本路上驾驶练习模拟器（浏览器版，three.js）。

## 地图

- **若葉市**：四车道的中央通り（公交专用道）、有路面电车的駅前通り（一个有安全地带的车站、一个没有）、踏切、商店街单行窄路、樱花大道、坡上的团地和寺庙、市役所、商场、小学。
- **海岸**：沿海国道、海水浴场、港口、灯台，往北是海崖山路。
- **高速**：若葉IC → 青葉隧道 → 青葉PA（减速车道与汇入）→ 施工变道 → 山手出口。
- **山手町**：役场、道の駅、温泉、梯田间的农道窄路。

## 功能

- 第一人称驾驶舱（右舵）：仪表盘、方向盘、三面后视镜、灯光和雨刷拨杆
- 交规判定：信号、一时停止、踏切、让行行人、限速、转向灯与变道合图、公交专用道、单行道、路面电车规则、高速（最低速度、车距、追越车线、ETC）等，100 分减点制
- 事件：小孩冲出、故障车、自行车、摩托车死角、紧急车辆、路边车辆驶出
- 昼夜、雨雪（路面变滑、其他车辆视野和反应变化、行人撑伞）、夜景
- 三种模式：检定路线、自由行驶 / 导航（点地图选目的地）、高速教习；中文 / 日本語；键盘、鼠标、触屏

## 运行

源文件是 `app.html`（页面主体）。改完后运行 `python3 build.py` 生成可独立打开的 `index.html`（GitHub Pages 用的就是它）。本地预览：

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000/ 。需要联网加载 three.js r128（cdnjs）和 Google Fonts。

## 操作

键盘：W/S 油门刹车 · A/D 方向 · Q/E 转向灯 · Shift 换挡（P→R→N→D，X 反向，需踩住刹车）· Space 手刹 · 移动鼠标转视角 · V 车内/车外 · P 暂停

手机：按住画面下方的方向盘转动打方向 · 左下按住挡位钮上下滑换挡，下面是手刹 · 右摇杆上油门、下刹车、左右拨转向灯、双击换视角 · 在画面其它地方滑动转头

起步：踩住刹车 → 挂 D → 松手刹。到终点：靠左停稳 → 挂 P → 拉手刹。
